# iCore Canonical Frontend Prototype

Static clickable prototype with two workspaces:

1. **Canonical Admin / Maintenance**
   - Overview dashboard
   - Canonical entities
   - Relations
   - Semantic attribute registry
   - Versioning and change requests
   - Quality and conflict monitoring

2. **Use Case Onboarding**
   - Use case metadata
   - Source data model
   - Mapping to central canonical
   - Compatibility validation
   - Versioned mapping contract publication

## Run
Open `index.html` directly in a browser or serve the directory with any static web server.

Example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.
